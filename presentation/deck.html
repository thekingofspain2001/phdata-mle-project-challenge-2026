Listings with blanks get turned away

Problem

A seller's listing is missing the bathroom count or the plot size. The API rejects the whole request. No price comes back.

Impact

Up to 10–20% of live requests stall. The agent phones back, the seller waits, the valuation queue stops.

Cost

Every rejected listing is a conversation restarted and a deal delayed. Coverage, not accuracy, is what leaks.

Summary: similar homes win

Twelve homes, four groups of three. Each group runs 25% bigger than the last; labels are living area in sq ft. Click for each approach.

Average Value

Add all twelve sizes, divide by twelve. One city-wide number fills every blank. Simple; ignores the house.

Mean value

Sort the row, take the middle. Mansions stop skewing the answer. Still one number for all blanks.

Nearest Neighbor

Take the 5 nearest sizes; closer homes count more. Each blank gets its own answer from its own street.

Summary: which value to fill

Average and middle give every blank one city-wide number. Similar homes answer per street — and on the fields that move price, that measures 8–21% closer.

What the test actually showed

How it was tested

21,613 sales, 15% of every numeric field blanked at random. Mean, median and NN(5) distance-weighted each refilled the blanks; error measured against the values we hid. The seven nullable fields the prediction API accepts, zipcode excluded because it is required and never imputed.
